## 一、项目概述

### 1.1 任务背景

4. **可交付**：提供可运行网址 + 完整工程 + 自动化测试。

### 1.3 完成情况

- ✅ 接入原站 40+ 个 API 端点，4 个数据源（财联社/Tencent/Tushare/PostgreSQL + Kronos AI）

## 二、目标站点技术分析（逆向工程）

### 2.1 技术栈识别
通过抓取站点入口 HTML 与 JS bundle，识别出：

| 层面 | 技术 |
|---|---|
| 前端框架 | Vue 3（Options + Composition API 混用） |
| 构建工具 | Webpack 5（vue-cli 产物，按需懒加载 chunk） |
| UI 组件库 | Element Plus（含中文 locale） |
| 数据请求 | Axios（baseURL 指向独立 API 服务） |
| 图表 | ECharts（懒加载 `chunk-echarts`）+ D3（气泡图/流向图） |
| 状态管理 | Vuex（自选股/用户态） |
| 数据源 | 腾讯财经行情、财联社资讯、Tushare、PostgreSQL、Kronos 时序模型 |

### 2.2 路由与组件还原
- 从 `app.*.js` 的 webpack 运行时解析出 **chunk 哈希映射表**，据此批量下载全部 27 个懒加载 chunk；
- 从编译产物反推出完整路由表（20 条，含每页 meta 标题）与组件树（首页由 8 个子组件组成）；
- 提取全部 API 契约（路径、参数、响应结构）与 CSS 设计令牌（主题色 `#409eff`、间距、圆角体系）。

### 2.3 关键发现
- 站点存在**版本迭代**（本次工作中捕获到两次重新部署，chunk 哈希变化），说明数据层与前端结构仍在演进，复现需以实时接口为准；
- 首页部分组件（知识图谱、自选股情报列表）在新版本中已从模板移除（`display:none` 占位），复现时以当前线上行为为准。

## 三、系统架构

```
┌────────────────────────────────────────────────────┐
│                     浏览器（Vue 3 SPA）              │
│  21 路由页 · Element Plus · ECharts · 深色主题      │
└──────────────┬──────────────────────┬──────────────┘
               │ /                   │ /api /kronos
        ┌──────▼───────┐      ┌──────▼───────┐
        │ Nginx（部署层）│      │ Node 服务      │
        │ 静态资源/HTTPS │◄────►│ serve.mjs     │
        └──────────────┘      │ ①静态文件服务   │
                              │ ②API反向代理    │
                              │ ③本地缓存降级   │
                              └──────┬────────┘
                    ┌─────────────────┼─────────────────┐
                    ▼                 ▼                 ▼
         gupiao-api.yaozhineng.com  Kronos HF Space   本地 mock
         财联社/腾讯/Tushare/PG       AI 价格预测        (接口不可用时)
```

### 3.1 前端工程
- **自研 Vue SFC 编译插件**（`build/vue-sfc-plugin.mjs`）：基于 `@vue/compiler-sfc` 实现 `.vue` 单文件组件的解析、`<script setup>` 编译、模板编译（含 scopeId 注入）、scoped CSS 抽取与运行时注入——不依赖 Vite/Webpack 即可独立构建；
- **纯 Rollup 构建链**：`@rollup/plugin-node-resolve + commonjs + replace`，产物按页面代码分割（21 个 chunk），兼容受限环境（无子进程可用）；
- **路由级懒加载**：与 Vue Router 动态 `import()` 结合，首屏仅加载主包与当前页。

### 3.2 数据层
- `src/api/index.js` 封装全部端点：资讯（头条/国内/外围/个股）、行情（实时/核心/活跃/K线）、评分（十倍/趋势）、资金流、盈利预测、监控事件、Agent 事件传导、Kronos 预测；
- **本地缓存层 CacheManager**（自研）：localStorage 缓存 + TTL + 命中秒开 + 后台静默刷新 + 过期数据兜底；
- **确定性降级**：K 线等不稳定接口不可用时，用"种子=股票代码"的伪随机生成器产出**可复现**的模拟数据，保证演示不崩溃且结果稳定。

## 六、测试与验证

### 6.1 自动化冒烟测试（jsdom，无浏览器依赖）
- 将应用构建为 CJS 单包，挂载到 jsdom 环境（补齐 DOM/Canvas/网络全局），驱动 Vue Router 逐页导航；
- 断言：页面关键区块渲染、渲染内容长度、**全局 JS 错误捕获（window.onerror + unhandledRejection）**；
- 结果：**首页 12 项区块检查全过；15 个页面全部渲染；0 JS 错误**。

### 6.2 真实数据验证
- 通过本地代理逐项验证：新闻头条、指数行情、个股行情、AI 分析、资金流、盈利预测、风口龙头（含 flow_data/上游/下游）、机构热门股、Agent 事件列表与详情、Kronos 预测全链路（创建任务 → 轮询 → 结果）。

### 6.3 服务稳定性
- 代理层修复 `ERR_HTTP_HEADERS_SENT` 崩溃缺陷（响应头已发送时不再重复写头），30 并发请求压测全部通过；
- 增加进程级 `uncaughtException` 兜底，单个请求异常不影响整体服务。

## 七、工程亮点

1. **完整逆向链路**：入口 HTML → webpack chunk 映射 → 懒加载 bundle 批量下载 → 组件树/API/CSS 还原，方法论可复用；
2. **自研构建链**：脱离 Vite/Webpack，用 `@vue/compiler-sfc` + Rollup 独立完成 SFC 工程化，深入理解 Vue 编译原理；
3. **前后端一体交付**：单个 Node 进程完成静态服务 + 多源代理 + 缓存降级，部署极简（宝塔 6 步上线）；
4. **测试驱动**：jsdom 全页面自动化回归，无需浏览器即可验证，保障持续交付质量；
5. **体验细节**：深色主题、缓存标注、确定性降级、分页滚动优化等，超出"照搬"层面。
